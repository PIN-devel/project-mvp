# MVP-381 — Spending Intelligence Finale

`/insights`의 순서는 밝은 분석 진입 화면 → 분석 실행·대기 → Navy 시각화 무대(소비 구조 → 시간 흐름 → 가맹점·거래 탐색) → 밝은 AI 해석 → 목표 선택이다. 현재 범위와 거래 데이터에 대해 분석을 성공했을 때만 결과를 보여준다. 기존 Signal Mint, 분석 요청·결과 계약, 최소 10건 규칙과 목표 선택·저장 로직을 유지한다.

## 세 장면

- **소비 구조:** 바깥 고리의 각도는 카테고리별 금액 비중, 안쪽 고리는 거래 수 비중이다. 총액은 고정하고 카테고리 선택·호버·포커스로 세 장면의 강조를 연결한다.
- **시간 흐름:** 실제 첫 거래일부터 마지막 거래일까지 일별 합계. 93일을 넘으면 월별 합계를 사용한다. 거래가 없는 중간 구간만 0원으로 채우고 관측 범위 밖은 그리지 않는다. 일부 월이 포함될 수 있다는 안내를 제공한다.
- **거래 탐색:** 같은 카테고리·가맹점 거래를 묶고 원의 면적을 금액에 비례시킨다. 충돌 없이 결정적으로 배치한다. 35개를 넘으면 나머지를 명시적인 합계 그룹으로 표시하고 모든 가맹점은 선택 목록에서 확인할 수 있다. 위치는 데이터의 거리·시간·유사성을 인코딩하지 않는다.

## 분석 경험 복원

서버에 분석 이력 저장 API가 없어 성공한 AI 결과, 완료 시각, 필터와 거래 변경 감지용 서명만 사용자 로그인 세션별 Web Storage에 저장한다. 원본 거래·카드 정보·시각화 집계는 복제하지 않는다. 같은 범위와 데이터에서는 결과를 복원하고, 필터·거래 변경 시 결과를 숨겨 재분석을 안내한다. 실패는 기존 성공 결과를 덮어쓰지 않는다. 로그아웃·계정 전환 시 관련 저장값과 쿼리를 제거한다. 저장 공간이 제한돼도 현재 화면의 성공 결과는 표시한다.

## 집계 기준

기존 `/api/transactions`와 `/api/categories`의 검증된 응답을 사용한다. 현재 조회 필터 결과에서 취소 상태(`취소`, `canceled`, `cancelled`), 0원·음수, 유효하지 않은 날짜·금액을 제외한다. 각 제외 건수와 집계 구간을 화면에 명시한다. 이는 양수 소비 금액의 합계이며 환불을 차감한 순현금 흐름이 아니다.

세 시각화의 금액 합계는 동일한 원본 거래 집합과 일치한다. 비중은 표시 단계에서만 반올림한다. AI는 기존 필터 대상 거래를 그대로 사용하며, 시각화의 집계 제외와 AI 대상 거래 수를 구별한다. 목표 후보는 기존의 거래월·분류·취소 제외 계약을 유지한다. 예측·절감 성과·자산 추이 계산은 사용하지 않는다.

## 상호작용과 접근성

고리·가맹점 원은 키보드 Enter/Space로 선택할 수 있다. 고리에는 동등한 텍스트 목록, 시간·가맹점에는 네이티브 선택 목록과 상세 정보가 있다. 작은 원을 직접 누르지 않아도 모든 기록에 접근할 수 있다. 선택 상태는 `aria-pressed`, 상세 갱신은 `aria-live`로 제공한다.

Desktop에서는 세 장면에 약 88svh의 최소 공간을 주고 우측의 키보드 접근 가능한 장면 안내로 이동할 수 있다. 화면 중앙과 교차하는 장면을 IntersectionObserver로 감지하며 스크롤을 가로채거나 고정하지 않는다. 무대에서 헤더는 물러나지만 Hover/Focus로 복귀하고, 무대를 벗어나면 헤더와 밝은 제품 화면이 돌아온다. 작은 화면에서 장면을 한 열로 구성하고 장면 안내를 생략하며 시간축만 내부 스크롤을 허용한다. 스크롤 진입 모션은 한 번만 실행하며 중요한 정보는 항상 표시한다. `prefers-reduced-motion`에서는 그리기·진입 애니메이션과 선택 전환을 제거한다. 새 프로덕션 의존성은 추가하지 않았다.

새 분석 성공 시 첫 고리의 실제 중심에서 Mint 신호가 퍼지고, 약 440ms의 원형 aperture로 Navy 무대가 열린다. 최초 원형 영역에는 금액과 고리가 이미 보이며 결과를 애니메이션 완료까지 기다리게 하지 않는다. 기하 정보는 준비·진입 시만 읽고 스크롤마다 계산하지 않는다. 저장된 결과 복원·첫 장면 건너뛰기·Reduced Motion에서는 aperture를 재생하지 않는다. 중단된 모션에도 최종 표면으로 복귀하는 정리 처리를 둔다. 마지막 장면 뒤에서는 별도의 역재생 없이 짧은 정적인 색조 여백을 거쳐 밝은 해석·행동 구간으로 돌아온다.
